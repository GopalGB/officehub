# Review

The baseline browser reproduction placed the drag preview roughly 240 px right and 80 px below the pointer-relative position. The page's persistent animation transform establishes a containing block for fixed descendants. A body portal removes that offset, and the viewport modifier bounds the resulting preview.

The board's original member predicate omitted sub-owners. Its replacement shares the existing central project-access rules and combines scope, status and owner filters with AND. CSV has no new data-fetch path: it exports exactly the displayed, authorized records. Formula-like strings are quoted and neutralized, and user credential fields are never selected for board props or CSV.

Browser checks exercise mouse, keyboard and touch moves, same-column order, Escape/outside rollback, scope forgery, member/manager exports, replay, reduced motion, long titles and narrow layouts. Manager-only summary rendering is checked separately from the board. Pending saves disable move handles without falsely showing permission locks, and focus returns after saving.

Final verification and any automated review findings are recorded in the pull request. Windows deployment remains the user's existing guarded no-admin updater; this cloud workspace cannot deploy to the office server.
