# Reliable project tracking and manager rollups

Make project movement stay under the pointer, export the authorized board to CSV, and show a concise per-person project summary plus an animated project journey.

Success criteria:
- Pointer/touch/keyboard moves persist, cancel/outside drops restore the card, and the drag preview stays inside the viewport without page overflow.
- Board and CSV share the same filters: managers see all team work; members see owned, sub-owned and explicitly shared projects only.
- Team overview shows counts above commitments without project names, and each project has a minimal replayable journey with reduced-motion support and honest missing dates.

No schema, deployment-policy, or credential changes are needed.
