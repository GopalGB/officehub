# Goal: A simpler Catalyst workspace

Make the everyday project flow easier to scan using Catalyst's existing navy,
orange, and blue palette. Keep recorded work, permissions, and optional detail
available without presenting every control at once.

Success: three clear project sections; one primary timeline with an optional
schedule; simpler project creation, navigation, and manager counts on mobile and
desktop. Preserve legacy section links, assignment rules, history, and exports.
No schema, authentication, dependency, or server policy changes.
